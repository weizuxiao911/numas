浏览器唤起 numas://serve 失败(没有 handler 注册)。需要先在系统上安装 numas 桌面版 / CLI。

检测到的平台:

macOS 安装方法:

  1. 从 GitHub Releases 下载 numas-darwin-arm64.zip 或 numas-darwin-x64.zip
  2. 解压后将 numas 二进制移到 /usr/local/bin/:
unzip numas-darwin-arm64.zip
sudo mv numas /usr/local/bin/
numas serve --port 4096 &

Linux 安装方法:

  1. 从 GitHub Releases 下载 numas-linux-x64.tar.gz
  2. 解压后移动到 PATH:
tar -xzf numas-linux-x64.tar.gz
sudo mv numas /usr/local/bin/
numas serve --port 4096 &

Windows 安装方法:

  1. 从 GitHub Releases 下载 numas-windows-x64.zip
  2. 解压到任意目录,把 numas.exe 加入 PATH,或:
Expand-Archive numas-windows-x64.zip
[Environment]::SetEnvironmentVariable("Path", "$env:Path;C:\numas", "User")
numas serve --port 4096
